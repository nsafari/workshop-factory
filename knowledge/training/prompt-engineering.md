## تکنیک‌های پایه

### الگوهای اساسی
| الگو | توضیح | مثال |
|------|-------|------|
| **Zero-shot** | دستور مستقیم، بدون مثال | «این مقاله را خلاصه کن» |
| **Few-shot** | ارائه مثال برای راهنمایی | «۳ مثال از خلاصه‌نویسی بده، بعد این را خلاصه کن» |
| **Chain-of-thought** | استدلال گام به گام | «قدم به قدم فکر کن و بعد پاسخ بده» |
| **Tree-of-thought** | کاوش مسیرهای استدلالی مختلف | «چند راه حل متفاوت پیشنهاد بده» |
| **Role prompting** | اختصاص شخصیت/تخصص | «تو یک متخصص آموزش هستی...» |

### چارچوب RTF (برای کاربران غیرفنی)
- **R (Role)**: هوش مصنوعی چه کسی باشد؟
- **T (Task)**: دقیقاً چه کاری انجام دهد؟
- **F (Format)**: خروجی چه شکلی باشد؟

**مثال**:
```
تو یک مشاور آموزشی هستی (R)
یک طرح درس برای درس ریاضی پایه هفتم بنویس (T)
قالب: هدف، مدت، فعالیت‌ها، ارزیابی (F)
```

## مهندسی زمینه (Context Engineering)

### اجزای کلیدی
1. **زمینه دستورالعملی**: سیستم پرامپت‌ها
2. **زمینه دانشی**: داده‌های بازیابی شده (RAG)
3. **زمینه ابزارها**: توابع در دسترس
4. **مدیریت حافظه**: تاریخچه مکالمه
5. **بودجه توکن**: بهینه‌سازی استفاده

### تفاوت پرامپت‌نویسی و مهندسی زمینه
| پرامپت‌نویسی | مهندسی زمینه |
|-------------|-------------|
| نوشتن یک پرامپت خوب | طراحی کل سیستم تعامل |
| تک وظیفه‌ای | چند وظیفه‌ای |
| بدون حافظه | با حافظه و ابزارها |

## دوره‌های آموزشی پیشنهادی

### برای معلمان
1. **پایه** (۴ ساعت): مفاهیم، محدودیت‌ها، ارزیابی خروجی
2. **عملی** (۸ ساعت): تولید محتوا، ارزیابی، بازخورد
3. **پیشرفته** (۴ ساعت): طراحی درس هوشمند

### برای مدیران
1. **آگاهی** (۴ ساعت): قابلیت‌ها، ریسک‌ها، فرصت‌ها
2. **کاربرد** (۸ ساعت): تحلیل داده، گزارش‌دهی، تصمیم‌گیری

## نکات عملی

### ✅ انجام دهید
- از قالب‌های مشخص استفاده کنید
- خروجی را همیشه بررسی کنید
- با مثال شروع کنید
- نقش و تخصص تعیین کنید

### ❌ انجام ندهید
- انتظار کامل بودن خروجی بدون ویرایش
- اعتماد کورکورانه به اطلاعات
- استفاده از اطلاعات حساس در پرامپت
- نادیده گرفتن سوگیری‌های احتمالی
