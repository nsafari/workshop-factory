# برنامه‌ریزی درسی CLIL
## CLIL Lesson Planning

---

## اصول کلیدی

### ۱. اهداف یادگیری دوگانه
هر درس CLIL باید **دو نوع هدف** داشته باشد:

```
هدف محتوایی (Content Objective)
└── دانش‌آموز چه چیزی یاد می‌گیرد؟

هدف زبانی (Language Objective)  
└── دانش‌آموز چه زبانی را تمرین می‌کند؟
```

### مثال
| نوع هدف | نمونه |
|---------|-------|
| محتوایی | دانش‌آموز مراحل چرخه آب را توضیح می‌دهد |
| زبانی | دانش‌آموز از افعال زمان حال ساده استفاده می‌کند |

---

## ساختار درس CLIL

### مدل ۳ مرحله‌ای

```
پیش‌فعالیت (Pre-Activity)
├── فعال‌سازی دانش قبلی
├── معرفی واژگان کلیدی
└── ایجاد انگیزه

فعالیت اصلی (Main Activity)
├── ارائه محتوا
├── تمرین هدایت‌شده
└── کار گروهی

پس‌فعالیت (Post-Activity)
├── خلاصه‌سازی
├── ارزیابی
└── اتصال به دنیای واقعی
```

---

## الگوی زمانی پیشنهادی

### درس ۴۵ دقیقه‌ای
| مرحله | زمان | فعالیت |
|-------|------|--------|
| پیش‌فعالیت | ۱۰ دقیقه | معرفی موضوع، واژگان، سؤال انگیزشی |
| فعالیت اصلی | ۲۵ دقیقه | ارائه + تمرین + کار گروهی |
| پس‌فعالیت | ۱۰ دقیقه | خلاصه، ارزیابی، تکلیف |

### درس ۹۰ دقیقه‌ای
| مرحله | زمان | فعالیت |
|-------|------|--------|
| پیش‌فعالیت | ۱۵ دقیقه | گرم‌کردن، واژگان، اهداف |
| بخش اول | ۳۰ دقیقه | ارائه محتوا + تمرین |
| استراحت | ۱۰ دقیقه | - |
| بخش دوم | ۲۵ دقیقه | کار گروهی + ارائه |
| پس‌فعالیت | ۱۰ دقیقه | جمع‌بندی، ارزیابی |

---

## طراحی فعالیت‌ها

### اصل تعادل
```
محتوا (Content)
├── ۴۰٪ ارائه جدید
├── ۴۰٪ تمرین و کاربرد
└── ۲۰٪ ارزیابی و بازخورد

زبان (Language)
├── ۳۰٪ ورودی (خواندن، گوش دادن)
├── ۴۰٪ پردازش (بحث، نوشتن)
└── ۳۰٪ خروجی (ارائه، توضیح)
```

### انواع فعالیت
| نوع | هدف | مثال |
|-----|-----|------|
| ورودی | دریافت اطلاعات | خواندن متن، تماشای ویدیو |
| پردازش | فهم و تحلیل | بحث گروهی، نقشه ذهنی |
| خروجی | تولید و ارائه | ارائه، نوشتن گزارش |

---

## نکات عملی

### ۱. انتخاب محتوا
- محتوا باید **مرتبط** با سطح دانش‌آموز باشد
- از **مواد اصیل** استفاده کنید (نه فقط متن‌های آموزشی)
- **عمق مناسب** را رعایت کنید

### ۲. مدیریت زبان
- **واژگان کلیدی** را قبل از درس معرفی کنید
- از **جملات قاب** استفاده کنید
- **پشتیبانی بصری** فراهم کنید

### ۳. ارزیابی
- ارزیابی **فرآیندمحور** نه فقط نتیجه‌محور
- **بازخورد فوری** بدهید
- **خودارزیابی** را تشویق کنید
