# بلوم و CLIL
## Bloom's Taxonomy in CLIL

---

## سطوح شناختی بلوم

### هرم بلوم (نسخه بازنگری‌شده)
```
        ┌─────────────┐
        │   خلق (Create)      │  ← سطح بالا
        ├─────────────┤
        │   ارزیابی (Evaluate)    │
        ├─────────────┤
        │   تحلیل (Analyze)     │
        ├─────────────┤
        │   کاربرد (Apply)      │
        ├─────────────┤
        │   فهم (Understand)   │
        ├─────────────┤
        │   دانش (Remember)    │  ← سطح پایین
        └─────────────┘
```

---

## فعل‌های یادگیری برای هر سطح

### ۱. دانش (Remember)
> یادآوری اطلاعات

| فعل | معادل فارسی | مثال |
|-----|------------|------|
| List | لیست کردن | مراحل چرخه آب را لیست کنید |
| Define | تعریف کردن | فتوسنتز را تعریف کنید |
| Name | نام بردن | بخش‌های گیاه را نام ببرید |
| Recall | یادآوری | نکات کلیدی درس را یادآوری کنید |
| Identify | شناسایی | عوامل مؤثر بر رشد را شناسایی کنید |

### ۲. فهم (Understand)
> درک معنا

| فعل | معادل فارسی | مثال |
|-----|------------|------|
| Explain | توضیح دادن | فتوسنتز را توضیح دهید |
| Describe | توصیف کردن | مراحل چرخه آب را توصیف کنید |
| Summarize | خلاصه کردن | نکات اصلی را خلاصه کنید |
| Interpret | تفسیر کردن | نمودار را تفسیر کنید |
| Compare | مقایسه کردن | دو اکوسیستم را مقایسه کنید |

### ۳. کاربرد (Apply)
> استفاده در موقعیت جدید

| فعل | معادل فارسی | مثال |
|-----|------------|------|
| Use | استفاده کردن | از فرمول استفاده کنید |
| Solve | حل کردن | مسئله را حل کنید |
| Demonstrate | نشان دادن | آزمایش را نشان دهید |
| Calculate | محاسبه کردن | سرعت را محاسبه کنید |
| Apply | به کار بردن | قانون را به کار ببرید |

### ۴. تحلیل (Analyze)
> تجزیه به اجزا

| فعل | معادل فارسی | مثال |
|-----|------------|------|
| Analyze | تحلیل کردن | داده‌ها را تحلیل کنید |
| Compare | مقایسه کردن | دو روش را مقایسه کنید |
| Contrast | تضاد کردن | تفاوت‌ها را مشخص کنید |
| Examine | بررسی کردن | علل را بررسی کنید |
| Classify | طبقه‌بندی | گیاهان را طبقه‌بندی کنید |

### ۵. ارزیابی (Evaluate)
> قضاوت و داوری

| فعل | معادل فارسی | مثال |
|-----|------------|------|
| Evaluate | ارزیابی کردن | نتایج را ارزیابی کنید |
| Judge | قضاوت کردن | کدام روش بهتر است؟ |
| Justify | توجیه کردن | چرا این روش را انتخاب کردید؟ |
| Defend | دفاع کردن | از نظر خود دفاع کنید |
| Critique | نقد کردن | مقاله را نقد کنید |

### ۶. خلق (Create)
> تولید چیز جدید

| فعل | معادل فارسی | مثال |
|-----|------------|------|
| Create | خلق کردن | آزمایش جدید طراحی کنید |
| Design | طراحی کردن | پروژه را طراحی کنید |
| Produce | تولید کردن | گزارش تولید کنید |
| Invent | ابداع کردن | راه‌حل جدید ابداع کنید |
| Compose | نوشتن | مقاله بنویسید |

## طراحی سؤال بر اساس بلوم

### سؤالات سطح پایین (دانش و فهم)
```
- چیست؟
- کیست؟
- کجاست؟
- چه زمانی؟
- چگونه؟
- توضیح دهید.
- خلاصه کنید.
```

### سؤالات سطح میانی (کاربرد و تحلیل)
```
- چرا؟
- چه ارتباطی دارد؟
- چه تفاوتی دارد؟
- چه الگویی می‌بینید؟
- اگر ... چه می‌شود؟
- از این اطلاعات چطور استفاده می‌کنید؟
```

### سؤالات سطح بالا (ارزیابی و خلق)
```
- نظر شما چیست؟
- کدام بهتر است؟ چرا؟
- چه جایگزینی پیشنهاد می‌کنید؟
- چطور می‌توان بهبود داد؟
- اگر می‌توانستید، چه تغییری می‌دادید؟
```

## کاربرد در CLIL

### طراحی فعالیت بر اساس سطح

| سطح بلوم | نوع فعالیت | مثال CLIL |
|----------|------------|-----------|
| دانش | لیست، تعریف | نام بخش‌های گیاه |
| فهم | توضیح، مقایسه | توضیح فتوسنتز |
| کاربرد | حل مسئله | پیش‌بینی رشد |
| تحلیل | بررسی، طبقه‌بندی | مقایسه اکوسیستم‌ها |
| ارزیابی | قضاوت، دفاع | ارزیابی نتایج |
| خلق | طراحی، ابداع | طراحی آزمایش |

### نکات مهم
- **تعادل** بین سطوح مختلف رعایت شود
- **تدریجی** از سطح پایین به بالا حرکت کنید
- **تفاوت‌های فردی** را در نظر بگیرید
- **پشتیبانی** مناسب برای سطوح بالاتر فراهم کنید
