# فعالیت‌های CLIL
## CLIL Activities

---

## طبقه‌بندی فعالیت‌ها

### بر اساس مرحله یادگیری
```
فعالیت‌های ورودی (Input Activities)
├── دریافت اطلاعات
├── خواندن و گوش دادن
└── مشاهده و تماشا

فعالیت‌های پردازش (Processing Activities)
├── فهم و تحلیل
├── بحث و گفتگو
└── سازماندهی اطلاعات

فعالیت‌های خروجی (Output Activities)
├── تولید و ارائه
├── نوشتن و صحبت کردن
└── خلق و ابداع
```

---

## فعالیت‌های ورودی (Input)

### ۱. خواندن هدفمند (Directed Reading)
```
مراحل:
۱. پیش‌خوانی: نگاه کلی به متن
۲. سؤال‌گذاری: نوشتن سؤالات قبل از خواندن
۳. خواندن: خواندن با دقت
۴. پاسخ‌گویی: پاسخ به سؤالات
۵. خلاصه‌نویسی: خلاصه کردن نکات کلیدی
```

### ۲. تماشای هدفمند (Directed Viewing)
```
مراحل:
۱. پیش‌بینی: حدس زدن محتوا
۲. تماشای اول: درک کلی
۳. تماشای دوم: جزئیات
۴. یادداشت‌برداری: نکات کلیدی
۵. بحث: اشتراک‌گذاری
```

### ۳. گوش دادن فعال (Active Listening)
```
مراحل:
۱. آماده‌سازی: مرور واژگان
۲. گوش دادن اول: درک کلی
۳. گوش دادن دوم: جزئیات
۴. یادداشت‌برداری: نکات مهم
۵. بازگویی: توضیح با کلمات خود
```

---

## فعالیت‌های پردازش (Processing)

### ۱. نقشه ذهنی (Mind Mapping)
```
مراحل:
۱. موضوع اصلی در مرکز
۲. شاخه‌های اصلی
۳. جزئیات هر شاخه
۴. ارتباطات بین شاخه‌ها
۵. رنگ‌بندی و نمادها
```

### ۲. طبقه‌بندی (Classification)
```
مراحل:
۱. شناسایی معیار طبقه‌بندی
۲. دسته‌بندی اطلاعات
۳. بررسی موارد استثنا
۴. نتیجه‌گیری
```

### ۳. مقایسه و تضاد (Compare & Contrast)
```
مراحل:
۱. شناسایی شباهت‌ها
۲. شناسایی تفاوت‌ها
۳. سازماندهی در جدول
۴. نتیجه‌گیری
```

### ۴. حل مسئله (Problem Solving)
```
مراحل:
۱. تعریف مسئله
۲. شناسایی راه‌حل‌های ممکن
۳. ارزیابی راه‌حل‌ها
۴. انتخاب بهترین راه‌حل
۵. اجرا و ارزیابی
```

---

## فعالیت‌های خروجی (Output)

### ۱. ارائه شفاهی (Oral Presentation)
```
مراحل:
۱. آماده‌سازی: نوشتن متن
۲. تمرین: تمرین جلوی آینه
۳. اجرا: ارائه به کلاس
۴. بازخورد: دریافت بازخورد
۵. بهبود: اصلاح برای دفعه بعد
```

### ۲. نوشتن هدفمند (Directed Writing)
```
انواع:
├── خلاصه‌نویسی
├── گزارش‌نویسی
├── نامه‌نویسی
└── مقاله‌نویسی
```

### ۳. پروژه گروهی (Group Project)
```
مراحل:
۱. تعیین موضوع
۲. تقسیم کار
۳. تحقیق
۴. تولید
۵. ارائه
۶. ارزیابی
```

### ۴. نمایش و بازی‌نقش (Role Play)
```
مراحل:
۱. تعیین سناریو
۲. تقسیم نقش‌ها
۳. آماده‌سازی متن
۴. اجرا
۵. بحث و بازخورد
```

## فعالیت‌های ترکیبی

### ۱. روش ۳-۲-۱
```
۳ چیز که یاد گرفتم
۲ چیز که جالب بود
۱ سؤال که دارم
```

### ۲. روش EXIT TICKET
```
قبل از خروج از کلاس:
├── ۱ نکته کلیدی بنویسید
├── ۱ سؤال بنویسید
└── ۱ ارتباط با زندگی واقعی بنویسید
```

### ۳. روش GALLERY WALK
```
مراحل:
۱. هر گروه پوستر می‌سازد
۲. پوسترها روی دیوار نصب می‌شود
۳. دانش‌آموزان دور می‌زنند
۴. نظر می‌نویسند
۵. بحث کلی
```

| هدف | فعالیت مناسب |
|-----|--------------|

| همکاری | کار گروهی، بازی‌نقش |
