# تکنیک‌های داربست‌زنی در CLIL
## Scaffolding Techniques

---

## تعریف
داربست‌زنی یعنی ارائه **پشتیبانی موقت** به دانش‌آموز تا بتواند کاری را انجام دهد که به تنهایی نمی‌تواند. با پیشرفت دانش‌آموز، این پشتیبانی کم می‌شود.

---

## انواع داربست‌زنی

### ۱. داربست‌زنی زبانی (Language Scaffolding)

#### جملات قاب (Sentence Frames)
```
برای توضیح:
"First, ... Then, ... Finally, ..."
"The reason for this is ..."

برای مقایسه:
"Compared to ..., ..."
"While ... on the other hand ..."

برای نتیجه‌گیری:
"Therefore, ..."
"In conclusion, ..."
```

#### واژگان کلیدی
```
قبل از درس:
├── لیست واژگان با تعریف ساده
├── تلفظ صحیح
└── مثال در جمله

حین درس:
├── تکرار واژگان در زمینه
├── استفاده از تصاویر
└── تمرین شفاهی
```

### ۲. داربست‌زنی بصری (Visual Scaffolding)

| ابزار | کاربرد | مثال |
|-------|--------|------|
| تصویر | توضیح مفاهیم انتزاعی | نمودار چرخه آب |
| جدول | سازماندهی اطلاعات | مقایسه ویژگی‌ها |
| نقشه ذهنی | نمایش روابط | ارتباط مفاهیم |
| خط زمانی | نمایش ترتیب | مراحل یک فرآیند |

### ۳. داربست‌زنی محتوایی (Content Scaffolding)

```
ساده → پیچیده
├── شروع با مفاهیم آشنا
├── افزایش تدریجی دشواری
└── اتصال به دانش قبلی

انتزاعی → ملموس
├── مثال‌های واقعی
├── تجربه عملی
└── شبیه‌سازی
```

---

## تکنیک‌های عملی

### ۱. روش GAP (Gather, Analyze, Present)

```
Gather (جمع‌آوری)
├── دانش‌آموز اطلاعات جمع‌آوری می‌کند
├── از منابع مختلف
└── با پشتیبانی معلم

Analyze (تحلیل)
├── دسته‌بندی اطلاعات
├── پیدا کردن الگوها
└── بحث گروهی

Present (ارائه)
├── ارائه نتایج
├── استفاده از زبان هدف
└── بازخورد همسالان
```

### ۲. روش Think-Pair-Share

```
Think (فکر کردن)
└── دانش‌آموز ۲ دقیقه فکر می‌کند

Pair (جفت شدن)
└── با یک همکلاسی بحث می‌کند

Share (اشتراک‌گذاری)
└── نتیجه را به کلاس ارائه می‌دهد
```

### ۳. روش Jigsaw

```
مرحله ۱: تقسیم به گروه‌های متخصص
├── هر گروه یک بخش را می‌خواند
├── متخصص آن بخش می‌شود
└── یادداشت‌برداری می‌کند

مرحله ۲: تقسیم به گروه‌های ترکیبی
├── هر عضو بخش خود را توضیح می‌دهد
├── بقیه گوش می‌دهند
└── یادداشت‌برداری می‌کنند

مرحله ۳: جمع‌بندی
├── گروه ترکیبی بحث می‌کند
├── ارائه کل موضوع
└── بازخورد معلم
```

## ابزارهای داربست‌زنی

### برای مبتدیان
- تصاویر و ویدیوهای ساده
- جملات کوتاه
- واژگان محدود
- تکرار زیاد

### برای متوسط
- متون طولانی‌تر
- بحث گروهی
- نوشتن پاراگراف
- مقایسه و تحلیل

### برای پیشرفته
- متون اصیل
- ارائه شفاهی
- نوشتن مقاله
- تحقیق مستقل

---

## نکات مهم

### انجام بدهید
- پشتیبانی را **تدریجاً** کم کنید
- از **تنوع** ابزارها استفاده کنید
- **بازخورد فوری** بدهید
- **خودارزیابی** را تشویق کنید

### انجام ندهید
- پشتیبانی را **ناگهانی** حذف نکنید
- فقط از **یک ابزار** استفاده نکنید
- **اشتباهات** را فوری اصلاح نکنید
- **تفاوت‌های فردی** را نادیده نگیرید
