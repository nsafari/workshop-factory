## پلتفرم‌های اصلی

### Google Workspace Studio
- **قابلیت**: توصیف اتوماسیون به زبان ساده
- **ویژگی**: Gemini 3 جریان‌های کاری را ایجاد می‌کند
- **مدیریت**: از Gmail، Chat، Drive قابل کنترل
- **مناسب برای**: معلمان و کارکنان اداری

### Microsoft Copilot Studio
- **قابلیت**: ایجاد راه‌حل به زبان طبیعی
- **ویژگی**: بدون نیاز به دانشمند داده یا توسعه‌دهنده
- **تجربه**: گرافیکی راهنما، بدون کد
- **تست**: ایجاد و انتشار در زمان واقعی

### Make.com (Maia)
- **قابلیت**: همکار هوش مصنوعی محاوره‌ای
- **ویژگی**: سازنده بصری سناریوها با شفافیت
- **ادغام**: بیش از ۳,۰۰۰ اپلیکیشن
- **یادگیری**: منحنی یادگیری کمتر برای کاربران تجاری

## آموزش برای کاربران غیرفنی

### چارچوب RTF
```
R (Role): نقش هوش مصنوعی را مشخص کنید
T (Task): وظیفه دقیق را تعریف کنید
F (Format): قالب خروجی را تعیین کنید
```

### مثال عملی
```
تو یک منشی هوشمند هستی (R)
ایمیل‌های دریافتی را دسته‌بندی و اولویت‌بندی کن (T)
قالب: فهرست با اولویت بالا/متوسط/پایین (F)
```

## دوره‌های آموزشی پیشنهادی

### سطح پایه (۴ ساعت)
1. مفاهیم پایه هوش مصنوعی
2. کار با Copilot در Word/Excel
3. تولید محتوا و ایمیل
4. ارزیابی و بهبود خروجی

### سطح متوسط (۸ ساعت)
1. مهندسی پرامپت پیشرفته
2. اتوماسیون جریان کار
3. تحلیل داده با هوش مصنوعی
4. ساخت ابزارهای ساده

### سطح پیشرفته (۸ ساعت)
1. ساخت جریان‌های کاری پیچیده
2. ادغام با سیستم‌های مختلف
3. مدیریت و نظارت
4. بهینه‌سازی عملکرد

## نکات اجرایی

### ✅ انجام دهید
- با ابزارهای ساده شروع کنید
- خروجی را همیشه بررسی کنید
- از داده‌های واقعی استفاده کنید
- با دیگران تجربه به اشتراک بگذارید

### ❌ انجام ندهید
- اطلاعات حساس وارد کنید
- خروجی را بدون بررسی استفاده کنید
- انتظار کامل بودن داشته باشید
- از یک ابزار برای همه کارها استفاده کنید
