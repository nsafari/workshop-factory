# اصول ارائه مطالب آموزشی
## Presentation & Worked Examples Best Practices

---

## ۱. طراحی اهداف یادگیری

### اصول SMART
```
S (Specific): مشخص
M (Measurable): قابل اندازه‌گیری
A (Achievable): دست‌یافتنی
R (Relevant): مرتبط
T (Time-bound): زمان‌دار
```

### الگوی نگارش هدف
```
[دانش‌آموز] + [فعل یادگیری] + [موضوع] + [شرایط] + [معیار]

مثال:
دانش‌آموز می‌تواند (فعل) مراحل چرخه آب را (موضوع)
با استفاده از نمودار (شرایط) توضیح دهد (معیار).
```

### فعل‌های مناسب برای اهداف
| سطح | فعل‌ها |
|-----|--------|
| دانش | نام ببرد، لیست کند، تعریف کند |
| فهم | توضیح دهد، خلاصه کند، مقایسه کند |
| کاربرد | استفاده کند، حل کند، نشان دهد |
| تحلیل | تحلیل کند، طبقه‌بندی کند، بررسی کند |
| ارزیابی | ارزیابی کند، قضاوت کند، دفاع کند |
| خلق | طراحی کند، تولید کند، ابداع کند |

## ۲. طراحی مثال‌های کارشده (Worked Examples)

### اصول کلیدی
```
۱. ساده شروع کنید
   └── با مثال‌های آشنا و ملموس

۲. گام‌به‌گام پیش بروید
   └── هر مرحله را جداگانه توضیح دهید

۳. فکر کردن را نشان دهید
   └── فرآیند تصمیم‌گیری را بلند بگویید

۴. اشتباهات را نشان دهید
   └── اشتباهات رایج و نحوه اصلاح

۵. تمرین بدهید
   └── مثال مشابه برای تمرین
```

### ساختار مثال کارشده
```
مرحله ۱: معرفی مسئله
├── توضیح موقعیت
├── نمایش داده‌ها
└── تعیین هدف

مرحله ۲: تحلیل
├── شناسایی اطلاعات مهم
├── تعیین روش حل
└── توضیح استدلال

مرحله ۳: حل
├── اجرای گام‌به‌گام
├── توضیح هر مرحله
└── نمایش نتیجه

مرحله ۴: بررسی
├── اعتبارسنجی جواب
├── بررسی منطقی بودن
└── بحث محدودیت‌ها

مرحله ۵: تعمیم
├── اتصال به مفاهیم کلی
├── مثال‌های مشابه
└── کاربردهای دیگر
```

## ۳. اصول طراحی اسلاید

### قانون ۱۰-۲۰-۳۰ (Guy Kawasaki)
```
۱۰: حداکثر ۱۰ اسلاید
۲۰: حداکثر ۲۰ دقیقه
۳۰: حداقل فونت ۳۰ پوینت
```

### ساختار اسلاید
```
اسلاید عنوان
├── عنوان اصلی
├── زیرعنوان
└── نام ارائه‌دهنده

اسلاید محتوا
├── عنوان واضح
├── ۳-۵ نکته کلیدی
├── تصویر یا نمودار
└── نتیجه‌گیری

اسلاید خلاصه
├── نکات کلیدی
├── اقدامات بعدی
└── اطلاعات تماس
```

### اصول بصری
```
رنگ‌ها
├── حداکثر ۳ رنگ اصلی
├── کنتراست بالا
└── سازگاری با برند

فونت‌ها
├── خوانا در اندازه بزرگ
├── حداکثر ۲ نوع فونت
└── سلسله‌مراتب واضح

تصاویر
├── مرتبط با محتوا
├── کیفیت بالا
└── ساده و واضح
```

## ۴. استراتژی‌های تعامل

### قبل از ارائه
```
۱. شناخت مخاطب
   ├── سطح دانش
   ├── نیازها
   └── انتظارات

۲. آماده‌سازی
   ├── تمرین
   ├── زمان‌بندی
   └── تجهیزات
```

### حین ارائه
```
۱. شروع قوی
   ├── سؤال انگیزشی
   ├── مثال ملموس
   └── داستان کوتاه

۲. حفظ توجه
   ├── تنوع در ارائه
   ├── سؤال پرسیدن
   └── فعالیت عملی

۳. مدیریت زمان
   ├── زمان‌بندی هر بخش
   ├── انعطاف‌پذیری
   └── جمع‌بندی
```

### بعد از ارائه
```
۱. بازخورد
   ├── نظرسنجی
   ├── سؤالات
   └── پیشنهادات

۲. پیگیری
   ├── تکالیف
   ├── منابع تکمیلی
   └── ارتباط بعدی
```

## ۵. مدیریت کلاس و کارگاه

### اصول کلیدی
```
۱. قوانین واضح
   ├── از ابتدا مشخص کنید
   ├── منصفانه اجرا کنید
   └── انعطاف‌پذیر باشید

۲. فضای امن
   ├── احترام متقابل
   ├── تشویق مشارکت
   └── مدیریت تعارض

۳. زمان‌بندی
   ├── شروع و پایان منظم
   ├── استراحت کافی
   └── انعطاف‌پذیری
```

### تکنیک‌های مشارکت
```
۱. سؤال‌پرسی
   ├── سؤالات باز
   ├── زمان فکر کردن
   └── تشویق پاسخ

۲. کار گروهی
   ├── تقسیم نقش‌ها
   ├── زمان مشخص
   └── ارائه نتایج

۳. بحث و گفتگو
   ├── موضوع مشخص
   ├── قوانین بحث
   └── جمع‌بندی
```

## ۶. ارزیابی و بازخورد

### انواع ارزیابی
```
ارزیابی تشخیصی (Diagnostic)
├── قبل از آموزش
├── شناسایی سطح
└── برنامه‌ریزی

ارزیابی تکوینی (Formative)
├── حین آموزش
├── بازخورد فوری
└── بهبود مستمر

ارزیابی تراکمی (Summative)
├── پایان آموزش
├── سنجش یادگیری
└── نمره‌دهی
```

### اصول بازخورد مؤثر
```
۱. خاص باشد
   └── نه کلی و مبهم

۲. سازنده باشد
   └── راه‌حل ارائه دهد

۳. به‌موقع باشد
   └── نه خیلی دیر

۴. متعادل باشد
   └── نقاط قوت و ضعف
```
