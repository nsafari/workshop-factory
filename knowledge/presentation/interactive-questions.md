# طراحی سؤالات تعاملی کارگاه
## Interactive Workshop Question Design

---

## چرا سؤال تعاملی؟

> سؤال خوب یادگیری را فعال می‌کند، نه فقط اطلاعات را بررسی می‌کند.

```
سؤال بد: «سه رکن دستیار هوشمند چیست؟»
→ پاسخ: حفظ‌کردن. تعامل کم. یادگیری سطحی.

سؤال خوب: «برای کار روزمره‌تان، کدام رکن سخت‌تر است؟ چرا؟»
→ پاسخ: تفکر، شخصی‌سازی، ارتباط با واقعیت. تعامل بالا.
```

---

## اصول طراحی سؤال

### ۱. باز باشد (Open-Ended)
```
❌ «آیا دستیار هوشمند مفید است؟»
✅ «دستیار هوشمند چطور می‌تواند کار شما را آسان‌تر کند؟»
```

### ۲. شخصی‌سازی شده (Personalized)
```
❌ «سه رکن را نام ببرید.»
✅ «برای کار خودتان، کدام رکن مهم‌تر است؟ چرا؟»
```

### ۳. ذهن را فعال می‌کند (Thought-Provoking)
```
❌ «پارامتر چیست؟»
✅ «اگر پارامترها را ولوم‌های یک دستگاه فرض کنیم، چرا تنظیم ۱۷۵ میلیارد ولوم با دست ممکن نیست؟»
```

### ۴. به دنیای واقعی وصل است (Relevant)
```
❌ «توجه چیست؟»
✅ «در جمله «علی به بانک رفت چون او پول لازم داشت»، چرا «او» به «علی» برمی‌گردد؟ این چه ربطی به کار مدل دارد؟»
```

### ۵. بی‌قضاوت (Non-Judgmental)
```
❌ «کدام پاسخ درست است؟»
✅ «نظر شما چیست؟»
```

---

## انواع سؤال تعاملی

### ۱. سؤال بازتابی (Reflection)
> شرکت‌کننده را به تجربه شخصی دعوت می‌کند

```
«از این بازی، چه حسی داشتید؟»
«کدام بخش برایتان سخت‌تر بود؟»
«اگر می‌توانستید، چه تغییری در این محتوا می‌دادید؟»
«چه چیزی برایتان جدید بود؟»
```

### ۲. سؤال سناریویی (Scenario)
> موقعیت فرضی برای سنجش کاربرد

```
«اگر یک دستیار هوشمند برای کار شما بسازید، از کجا شروع می‌کنید؟»
«فرض کنید مدل جواب غلط داد. چه می‌کنید؟»
«همسایه‌تان می‌گوید هوش مصنوعی جادویی است. چه می‌گویید؟»
```

### ۳. سؤال خلاقانه (Creative)
> تولید ایده یا راه‌حل جدید

```
«یک کاربرد جدید برای این ابزار در کار شما ابداع کنید.»
«اگر فقط ۱۰ دقیقه وقت داشتید، چه خودکارسازی می‌ساختید؟»
«دستیار هوشمند شما را چه اسمی می‌نامید؟ چرا؟»
```

### ۴. سؤال ارتباطی (Connection)
> اتصال محتوا به تجربه قبلی

```
«این مفهوم شبیه چه چیزی است که قبلاً دیده‌اید؟»
«در کار قبلی‌تان چه الگویی دیده‌اید که شبیه این است؟»
«این چه ربطی به کار روزمره‌تان دارد؟»
```

### ۵. سؤال چالشی (Challenge)
> به چالش کشیدن تفکر

```
«چرا این اتفاق می‌افتد؟ واقعاً چرا؟»
«اگر این جواب درست نبود، چه می‌شد؟»
«کدام بخش از این سناریو غیرمنطقی است؟ چرا؟»
```

### ۶. سؤال خودآگاهی (Self-Awareness)
> آگاهی به فرآیند یادگیری

```
«چه چیزی بیشتر از همه ذهن‌تان را درگیر کرد؟»
«از این بخش، چه سؤالی برای خودتان دارید؟»
«کدام بخش هنوز برایتان نامفهوم است؟»
```

### ۷. سؤال مشارکتی (Collaborative)
> دعوت به تعامل با دیگران

```
«از همسایه‌تان چه یاد گرفتید؟»
«با گروه خود یک مثال واقعی بزنید.»
«نظر گروه شما چیست؟ اتفاقی یا اختلافی؟»
```

---

## تطبیق با سطح بلوم

| سطح بلوم | نوع سؤال | مثال |
|----------|---------|------|
| **دانش** | یادآوری | «سه رکن را نام ببرید» |
| **فهم** | توضیح | «با زبان خودتان توضیح دهید» |
| **کاربرد** | استفاده | «برای کار خودتان مثال بزنید» |
| **تحلیل** | مقایسه | «چه تفاوتی دارد؟» |
| **ارزیابی** | قضاوت | «کدام بهتر است؟ چرا؟» |
| **خلق** | ابداع | «راه‌حل خودتان را پیشنهاد دهید» |

**قانون طلایی**: در هر بخش، حداقل یک سؤال از سطح متفاوت.

## زمان‌بندی سؤال در کارگاه

### الگوی پیشنهادی (برای بخش ۱۰-۱۵ دقیقه‌ای)

```
دقیقه ۰-۲: سؤال بازتابی یا سناریویی (شروع نرم)
    ↓
دقیقه ۲-۸: [محتوای اصلی]
    ↓
دقیقه ۸-۱۲: سؤال چالشی یا ارتباطی (تعمیق)
    ↓
دقیقه ۱۲-۱۵: سؤال خلاقانه یا مشارکتی (جمع‌بندی فعال)
```

### تعداد سؤال به ازای هر بخش

| مدت بخش | تعداد سؤال | نوع |
|---------|-----------|-----|
| ۲-۵ دقیقه | ۱ | بازتابی یا سناریویی |
| ۵-۱۰ دقیقه | ۱-۲ | بازتابی + چالشی |
| ۱۰-۱۵ دقیقه | ۲ | بازتابی + چالشی + خلاقانه |
| ۱۵+ دقیقه | ۲-۳ | ترکیبی از همه انواع |

## سؤال‌های انتهای کارگاه (نظرسنجی)

### ترکیب متوازن

```
۱. امتیازدهی (کمی) → ۱-۲ سؤال
۲. انتخابی (کیفی) → ۱-۲ سؤال
۳. متنی (توضیحی) → ۲-۳ سؤال
```

### نکات مهم

- سؤال اول ساده و گرم‌کننده باشد (امتیازدهی)
- سؤالات وسطی درباره بخش‌های خاص
- سؤال آخر باز و پایان‌باز (پیشنهاد بهبود)
- حداقل یک سؤال درباره احساس/نگرش (نه فقط دانش)

---

## تنوع در سؤال‌پرسی

### روش‌های مختلف

```
۱. سؤال از همه → دست بلند کنند
۲. سؤال از همه → در گروه بحث کنند → یک نفر گزارش دهد
۳. سؤال برای همسایه (think-pair-share)
۴. سؤال با رای‌گیری (مثل کوئیز)
۵. سؤال با نوشتن (مثل یادداشت ۳۰ ثانیه‌ای)
۶. سؤال چندگزینه‌ای سریع
```

### قانون ۳۰ ثانیه

> بعد از پرسیدن سؤال، حداقل ۵-۱۰ ثانیه سکوت کنید. شرکت‌کنندگان به وقت نیاز دارند.

## اشتباهات رایج

### ۱. سؤال خیلی کلی
```
❌ «نظرتان چیست؟»
✅ «نظرتان درباره X چیست؟ چرا؟»
```

### ۲. سؤال خیلی تخصصی
```
❌ «درباره ماتریس توجه بگویید»
✅ «در این جمله، چرا «او» به «علی» برمی‌گردد؟»
```

### ۳. سؤال تماشاگری (بی‌تعامل)
```
❌ «آیا موافقید؟»
✅ «کدام بخش برایتان مهم‌تر است؟ چرا؟»
```

### ۴. سؤال بدون زمینه
```
❌ «چرا مدل اشتباه می‌کند؟»
✅ «در مثال قیمت خانه، اگر داده اشتباه بدهیم چه می‌شود؟»
```

---

## چک‌لیست طراحی سؤال

قبل از نهایی‌کردن سؤالات هر بخش:

- [ ] آیا سؤال باز است؟ (نه بله/خیر)
- [ ] آیا شخصی‌سازی شده؟ (به کار شرکت‌کننده مربوط می‌شود)
- [ ] آیا سطح بلوم مناسب دارد؟ (تنوع)
- [ ] آیا به دنیای واقعی وصل است؟
- [ ] آیا بی‌قضاوت است؟ (نه سؤال امتحانی)
- [ ] آیا در ۵ ثانیه قابل فهم است؟
- [ ] آیا پاسخ آن قابل نوشتن در ۲-۳ جمله است؟
