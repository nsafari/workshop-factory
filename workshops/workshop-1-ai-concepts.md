## چرا این کارگاه مهم است؟

بیشتر مردم فقط با LLM سوال و جواب می‌کنند و نمی‌دانند پشت پرده چه اتفاقی می‌افتد. این کارگاه به شما نشان می‌دهد LLM چطور کار می‌کند تا بتوانید آن را در مسیر درست برای رسیدن به هدف هدایت کنید.

مثلاً آیا LLM واقعاً فکر می‌کند؟ پاسخ این سؤال برای نحوه استفاده شما از آن بسیار مهم است. وقتی بدانید LLM در فرایند تولید متن، بر اساس توزیع احتمالاتی آموخته‌شده، توکن‌های بعدی را پیش‌بینی می‌کند، بهتر می‌توانید پرامپت بنویسید و خروجی را ارزیابی کنید. این فرایند می‌تواند به رفتارهایی منجر شود که شبیه استدلال، برنامه‌ریزی و حل مسئله به نظر می‌رسند.

از طرفی، لایه‌های زیاد deep learning چطور به رسیدن به توابع پیچیده کمک می‌کنند؟ این توابع چطور در LLM بوجود می‌آیند و بکار می‌روند؟ وقتی این مفاهیم را بفهمید، می‌توانید درک کنید چرا LLM در بعضی کارها عالی و در بعضی کارها ضعیف است.

همچنین دانش چطور از داده‌های بدون برچسب که بیشتر داده‌های واقعی هستند استخراج می‌شود؟ در یادگیری خودنظارتی، خود داده‌ها سیگنال آموزشی را فراهم می‌کنند. چطور پارامترهای مدل این دانش را بازنمایی می‌کنند و چطور از آن برای پاسخ‌دهی استفاده می‌شود؟ فهم این فرآیند به شما کمک می‌کند از LLM به عنوان یک ابزار حرفه‌ای استفاده کنید، نه فقط یک چت‌بات ساده.

### بخش ۳: نحوه یادگیری LLM (۲۰ دقیقه)

#### ۳.۱ یادگیری خودنظارتی (Self-Supervised Learning) (۱۰ دقیقه)
- تفاوت یادگیری خودنظارتی با یادگیری بدون نظارت
- در یادگیری خودنظارتی، خود داده‌ها سیگنال آموزشی را فراهم می‌کنند
- پیش‌بینی کلمه بعدی: "گربه روی ___ نشست" → مدل از خود متن یاد می‌گیرد کلمه بعدی را پیش‌بینی کند (مثلاً «موکت»)
- چرا نیازی به برچسب‌گذاری دستی نیست؟

#### ۳.۲ بازنمایی اطلاعات در پارامترها (۵ دقیقه)
- دانش در یک «بردار» واحد ذخیره نمی‌شود؛ در سراسر پارامترهای مدل توزیع شده است
- نمایش‌های داخلی مدل چطور روابط بین کلمات را بازنمایی می‌کنند
- مثال: رابطه‌های معنایی مثل «پادشاه − مرد + زن ≈ ملکه»

#### ۳.۳ تفکیک مفاهیم: Parameters ≠ Data ≠ Context (۵ دقیقه)
- **پارامترها (Parameters)**: وزن‌های قابل تنظیم مدل که در طول آموزش یاد گرفته می‌شوند
- **داده‌های آموزشی (Training Data)**: متون و مثال‌هایی که مدل از آنها یاد می‌گیرد
- **زمینه (Context)**: متنی که شما در پرامپت به مدل می‌دهید
- این سه مفهوم متفاوت هستند و نباید با هم اشتباه گرفته شوند

### بخش ۴: عملی - آموزش یک مدل ساده (۲۵ دقیقه)

#### ۴.۱ معرفی مسئله (۵ دقیقه)
- پیش‌بینی قیمت خانه بر اساس متراژ
- داده‌های ساده

#### ۴.۲ کدنویسی زنده (۱۵ دقیقه)
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# داده‌های ساده: متراژ (متر مربع) و قیمت (میلیون تومان)
X = np.array([50, 60, 70, 80, 90, 100]).reshape(-1, 1)
y = np.array([250, 300, 350, 400, 450, 500])

# آموزش مدل
model = LinearRegression()
model.fit(X, y)

# پیش‌بینی
predictions = model.predict(X)

# نمایش نتایج
plt.scatter(X, y, color='blue', label='داده‌های واقعی')
plt.plot(X, predictions, color='red', label='پیش‌بینی مدل')
plt.xlabel('متراژ (متر مربع)')
plt.ylabel('قیمت (میلیون تومان)')
plt.title('پیش‌بینی قیمت خانه با رگرسیون خطی')
plt.legend()
plt.show()

# نمایش پارامترها
print(f"شیب (وزن): {model.coef_[0]:.2f}")
print(f"عرض از مبدأ (بایاس): {model.intercept_:.2f}")
print(f"R² (دقت مدل): {model.score(X, y):.2f}")
```

#### ۴.۳ توضیح نتایج (۵ دقیقه)
- شیب چه معنایی دارد؟
- چطور مدل از داده‌ها یاد می‌گیرد
- ارتباط با LLM
