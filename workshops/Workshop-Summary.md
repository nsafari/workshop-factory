# خلاصه کارگاه‌های هوش مصنوعی

---

## کارگاه ۱: آشنایی با مفاهیم هوش مصنوعی

### چرا این کارگاه مهم است؟

بیشتر مردم فقط با LLM سوال و جواب می‌کنند و نمی‌دانند پشت پرده چه اتفاقی می‌افتد. این کارگاه به شما نشان می‌دهد LLM چطور کار می‌کند تا بتوانید آن را در مسیر درست برای رسیدن به هدف هدایت کنید.

مثلاً آیا LLM واقعاً فکر می‌کند؟ پاسخ این سؤال برای نحوه استفاده شما از آن بسیار مهم است. وقتی بدانید LLM در فرایند تولید متن، بر اساس توزیع احتمالاتی آموخته‌شده، توکن‌های بعدی را پیش‌بینی می‌کند، بهتر می‌توانید پرامپت بنویسید و خروجی را ارزیابی کنید. این فرایند می‌تواند به رفتارهایی منجر شود که شبیه استدلال، برنامه‌ریزی و حل مسئله به نظر می‌رسند.

از طرفی، لایه‌های زیاد deep learning چطور به رسیدن به توابع پیچیده کمک می‌کنند؟ این توابع چطور در LLM بوجود می‌آیند و بکار می‌روند؟ وقتی این مفاهیم را بفهمید، می‌توانید درک کنید چرا LLM در بعضی کارها عالی و در بعضی کارها ضعیف است.

همچنین دانش چطور از داده‌های بدون برچسب که بیشتر داده‌های واقعی هستند استخراج می‌شود؟ در یادگیری خودنظارتی، خود داده‌ها سیگنال آموزشی را فراهم می‌کنند. چطور پارامترهای مدل این دانش را بازنمایی می‌کنند و چطور از آن برای پاسخ‌دهی استفاده می‌شود؟ فهم این فرآیند به شما کمک می‌کند از LLM به عنوان یک ابزار حرفه‌ای استفاده کنید، نه فقط یک چت‌بات ساده.

### اهداف یادگیری

بعد از این کارگاه، شما می‌توانید:
- تفاوت AI، ML و LLM را توضیح دهید
- درباره مفهوم «فکر کردن» در LLMها بحث کنید
- بفهمید پارامترهای یک LLM (مثلاً ۱۲B یا ۴B) یعنی چه
- معماری‌های مختلف Transformer (Encoder, Decoder, Encoder-Decoder) را بشناسید
- لایه‌های پنهان شبکه عصبی عمیق و نقش آنها در توابع پیچیده را درک کنید
- نقش Transformer در LLM را توضیح دهید
- بفهمید دانش چطور از آموزش استخراج می‌شود و یادگیری خودنظارتی چه نقشی در آن دارد
- چگونه اطلاعات و الگوهای آموخته‌شده در پارامترها و نمایش‌های داخلی مدل بازنمایی می‌شوند
- نقش پیش‌بینی در LLM را بدانید
- یک مدل ساده خطی آموزش ببینید و نتایج را روی نمودار ببینید

### ساختار کارگاه

**بخش ۱: مقدمه و مفاهیم پایه**
- هوش مصنوعی چیست؟
- یادگیری ماشین چیست؟
- مدل‌های زبانی بزرگ (LLM) چیست؟

**بخش ۲: پشت صحنه LLM**
- پارامترهای LLM

- Transformer چیست؟

**بخش ۳: نحوه یادگیری LLM**
- یادگیری خودنظارتی (Self-Supervised Learning)
- بازنمایی اطلاعات در پارامترها
- تفکیک مفاهیم: Parameters ≠ Data ≠ Context

## کارگاه ۲: مفهوم Agent و ابزارهای هوشمند

### چرا این کارگاه مهم است؟

یک LLM به‌تنهایی عمدتاً تولید محتوا انجام می‌دهد؛ یک Agent-based system می‌تواند از مدل برای تصمیم‌گیری و انتخاب/اجرای ابزارها در یک فرایند چندمرحله‌ای استفاده کند. این تفاوت کوچک، دنیای بزرگی دارد. اگر بتوانید Agent بسازید یا از ابزارهای هوشمند استفاده کنید، دیگر محدود به پاسخ‌های آماده نیستید. خودتان می‌توانید فرآیندها را خودکار کنید، داده‌ها را تحلیل کنید و وظایف پیچیده را قدم‌به‌قدم انجام دهید.

اما نکته مهم‌تر این است: یاد می‌گیرید چطور این ابزارها را کنترل کنید. Harnessing یعنی مهار کردن هوش مصنوعی، نه اینکه مهارش کند. وقتی بدانید چطور Guardrails بگذارید، چطور نظارت انسانی حفظ کنید و چطور از ابزارها استفاده کنید، می‌توانید ریسک خطا را کاهش دهید و مشخص کنید Agent در چه شرایطی باید متوقف شده و تصمیم را به انسان واگذار کند.

### اهداف یادگیری

بعد از این کارگاه، شما می‌توانید:
- مفهوم Agent و تفاوت آن با LLM ساده را توضیح دهید
- بفهمید چه زمانی Agent ارزشمند است
- نمونه مشکلات و راه‌حل‌ها با Agent را بشناسید
- محصولات رایج و ابزارهای اوپن‌سورس را معرفی کنید
- نحوه استفاده عملی از Agent را ببینید

### ساختار کارگاه

**بخش ۱: معرفی مفهوم Agent**
- LLM ساده در مقابل Agent
- Agent چیست؟
- چه زمانی استفاده از Agent ارزشمند است؟

**بخش ۲: مشکلات و راه‌حل‌ها با Agent**
- مشکل ۱: وظایف پیچیده
- مشکل ۲: نیاز به ابزارها
- مشکل ۳: فراموشی در مکالمه‌های طولانی
- مشکل ۴: خطا و بهبود

**بخش ۳: معرفی محصولات و ابزارها**
- محصولات رایج
- ابزارهای اوپن‌سورس
- Harnessing چیست؟

**بخش ۴: نمونه استفاده عملی**
- نمونه ۱: دستیار نوشتن
- نمونه ۲: تحلیل داده
- نمونه ۳: اتوماسیون وظایف
- نکات اجرایی

**بخش ۵: جمع‌بندی و سؤالات**
- خلاصه مفاهیم کلیدی
- سؤال و پاسخ

## کارگاه ۳: استفاده از OpenCode و oh-my-openagent

### چرا این کارگاه مهم است؟

شاید فکر کنید هوش مصنوعی فقط برای نوشتن ایمیل و خلاصه کردن مقاله مفید است. اما در دنیای برنامه‌نویسی، هوش مصنوعی می‌تواند همکار شما باشد. این کارگاه بر دو لایه استوار است: **لایه A، اصول پایدار**؛ مهارت‌هایی مثل کاوش در کد، تولید تست، ریفکتورینگ، اعتبارسنجی و بازبینی انسانی که مستقل از هر ابزاری کاربرد دارند. و **لایه B، پیاده‌سازی با ابزار**؛ ابزارهای مشخصی مثل OpenCode و oh-my-openagent که این اصول را عملی می‌کنند. اما مهم‌تر از خود ابزارها، یادگیری اصول پایدار است؛ چون ابزارها ممکن است تغییر کنند، ولی اصول می‌مانند.

نکته کلیدی این است: هوش مصنوعی جایگزین شما نمی‌شود، اما شما را قوی‌تر می‌کند. وقتی بدانید چطور از Agent برای شناسایی کد استفاده کنید، چطور تست‌های خودکار بسازید، چطور خروجی Agent را اعتبارسنجی کنید و چطور مدل‌های مختلف orchestration را انتخاب کنید، سرعت و کیفیت کارتان چند برابر می‌شود.

### اهداف یادگیری

**اصول پایدار (لایه A):**
- اصول کدنویسی Agentic و نحوه کاوش در کد را بفهمید
- برای پروژه تست بنویسید و خروجی Agent را اعتبارسنجی کنید
- کد را ریفکتور کنید
- مفهوم Orchestration و جداسازی برنامه‌ریزی از اجرا را بفهمید
- اهمیت مجوزهای ابزار و بازبینی انسانی را بدانید

**پیاده‌سازی با ابزار (لایه B):**
- OpenCode و oh-my-openagent را نصب و راه‌اندازی کنید
- از Ultrawork برای وظایف پیچیده استفاده کنید
- Categories و Skills را بشناسید و درست استفاده کنید
- Team Mode را برای پروژه‌های تیمی درک کنید

### ساختار کارگاه

**بخش ۱: معرفی ابزارها (لایه B)**
- OpenCode چیست؟
- oh-my-openagent چیست؟
- چرا این ابزارها مهم هستند؟
