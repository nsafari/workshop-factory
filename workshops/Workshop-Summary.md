# خلاصه کارگاه‌های هوش مصنوعی

---

## کارگاه ۱: آشنایی با مفاهیم هوش مصنوعی (۵۵ دقیقه)

### دو هدف کارگاه

**هدف ۱: دستیار هوشمند چیست و با اهداف شما چطور هماهنگ می‌شود؟**
شرکت‌کننده باید بتواند تعریف کند دستیار هوشمند با یک چت‌بات ساده چه فرقی دارد (سه رکن: دانش، مهارت، ابزار) و برای یک کار روزمرهٔ خودش مشخص کند چه دانش، چه مهارت و چه ابزاری لازم است — یعنی «دستیار» از یک انتزاع، به هدف شخصی او گره بخورد.

**هدف ۲: اعتماد به نفس کار با LLM**
شرکت‌کننده باید با ذهن خودش تجربه کرده باشد که «مدل همان کاری را انجام می‌دهد که من همین‌الان انجام دادم»: الگو را از داده کشف کردن (بازی قیمت خانه) و کلمهٔ بعد را پیش‌بینی کردن (بازی «آسمان امروز ...»)؛ و با پارامتر و توجه آشنا شود تا LLM دیگر برایش غریبه و جادویی نباشد. اعتماد از تجربهٔ دستی می‌آید، نه از توضیح.

نکتهٔ مشترک هر دو هدف: اطلاع از نحوهٔ کار مدل هدف نیست، وسیله است؛ کارگاه باید به مخاطب اعتماد به نفس مدیریت هوش مصنوعی بدهد و او را در موضع فعال (نه مشتری منفعل) قرار دهد.

### اهداف یادگیری

بعد از این کارگاه، شما می‌توانید:

**برای هدف ۱:**
- سه رکن دستیار هوشمند (دانش، مهارت، ابزار) را نام ببرید و تفاوتش را با چت ساده توضیح دهید
- برای یک کار روزمرهٔ خودتان سه رکن را مشخص کنید و بگویید دستیار چطور با هدف شما هماهنگ می‌شود

**برای هدف ۲:**
- یادگیری مدل را با بازی قیمت خانه توضیح دهید: الگو از داده کشف شد، کسی فرمول نداد
- پیش‌بینی کلمهٔ بعدی را با بازی «آسمان امروز ...» توضیح دهید و بگویید مدل بدون معلم یاد گرفته (پاسخ در دل متن است)
- پارامتر را با قیاس ولوم و از ۲ عددِ مدل قیمت خانه توضیح دهید
- مکانیزم توجه (Attention) را با جملهٔ «علی به بانک رفت چون او پول لازم داشت» نشان دهید

### ساختار کارگاه (دو جلسهٔ ۲۰ دقیقه‌ای + ۱۵ دقیقه استراحت)

**جلسهٔ ۱: دستیار هوشمند چیست و با اهداف شما چطور هماهنگ می‌شود؟ (هدف ۱)**
- دو هدف کارگاه
- یک صبح با دستیار هوشمند
- چرا با چت کردن ساده کافی نیست + سه رکن (دانش، مهارت، ابزار)
- این کارگاه برای کیست؟ + نقشهٔ سه کارگاه
- هماهنگی با اهداف شما: هر شرکت‌کننده یک کار روزمرهٔ خودش را با سه رکن توصیف می‌کند (think-pair-share)
- خلاصه + پل به جلسهٔ ۲ + سؤال استراحت

**جلسهٔ ۲: اعتماد به نفس کار با LLM (هدف ۲)**
- مرور: سه رکن را چیدید؛ حالا مغز همین دستیار را باز می‌کنیم
- بازی ۱: قیمت خانه (تو خودت مدلِ یادگیری ماشین هستی)
- بازی ۲: «آسمان امروز ...» (تو خودت LLM هستی)
- بدون معلم یاد گرفت؟ (خودنظارتی) + شبکه در یک خط + LLM در یک جمله
- پارامتر چیست؟ (از ۲ عددِ مدل قیمت خانه) + مقیاس واقعی
- Transformer و توجه (بازی «او»)
- چک‌لیست اعتماد + از مشتری به مدیر + تکلیف امروز و کارگاه بعدی

## کارگاه ۲: مفهوم Agent و ابزارهای هوشمند

### چرا این کارگاه مهم است؟

یک LLM به‌تنهایی عمدتاً تولید محتوا انجام می‌دهد؛ یک Agent-based system می‌تواند از مدل برای تصمیم‌گیری و انتخاب/اجرای ابزارها در یک فرایند چندمرحله‌ای استفاده کند. این تفاوت کوچک، دنیای بزرگی دارد. اگر بتوانید Agent بسازید یا از ابزارهای هوشمند استفاده کنید، دیگر محدود به پاسخ‌های آماده نیستید. خودتان می‌توانید فرآیندها را خودکار کنید، داده‌ها را تحلیل کنید و وظایف پیچیده را قدم‌به‌قدم انجام دهید.

اما نکته مهم‌تر این است: یاد می‌گیرید چطور این ابزارها را کنترل کنید. Harnessing یعنی مهار کردن هوش مصنوعی، نه اینکه مهارش کند. وقتی بدانید چطور Guardrails بگذارید، چطور نظارت انسانی حفظ کنید و چطور از ابزارها استفاده کنید، می‌توانید ریسک خطا را کاهش دهید و مشخص کنید Agent در چه شرایطی باید متوقف شده و تصمیم را به انسان واگذار کند.

### اهداف یادگیری

بعد از این کارگاه، شما می‌توانید:
- مفهوم Agent و تفاوت آن با LLM ساده را توضیح دهید
- بفهمید چه زمانی Agent ارزشمند است
- نمونه مشکلات و راه‌حل‌ها با Agent را بشناسید
- محصولات رایج و ابزارهای اوپن‌سورس را معرفی کنید
- نحوه استفاده عملی از Agent را ببینید

### ساختار کارگاه

**بخش ۱: معرفی مفهوم Agent**
- LLM ساده در مقابل Agent
- Agent چیست؟
- چه زمانی استفاده از Agent ارزشمند است؟

**بخش ۲: مشکلات و راه‌حل‌ها با Agent**
- مشکل ۱: وظایف پیچیده
- مشکل ۲: نیاز به ابزارها
- مشکل ۳: فراموشی در مکالمه‌های طولانی
- مشکل ۴: خطا و بهبود

**بخش ۳: معرفی محصولات و ابزارها**
- محصولات رایج
- ابزارهای اوپن‌سورس
- Harnessing چیست؟

**بخش ۴: نمونه استفاده عملی**
- نمونه ۱: دستیار نوشتن
- نمونه ۲: تحلیل داده
- نمونه ۳: اتوماسیون وظایف
- نکات اجرایی

**بخش ۵: جمع‌بندی و سؤالات**
- خلاصه مفاهیم کلیدی
- سؤال و پاسخ

## کارگاه ۳: استفاده از OpenCode و oh-my-openagent

### چرا این کارگاه مهم است؟

شاید فکر کنید هوش مصنوعی فقط برای نوشتن ایمیل و خلاصه کردن مقاله مفید است. اما در دنیای برنامه‌نویسی، هوش مصنوعی می‌تواند همکار شما باشد. این کارگاه بر دو لایه استوار است: **لایه A، اصول پایدار**؛ مهارت‌هایی مثل کاوش در کد، تولید تست، ریفکتورینگ، اعتبارسنجی و بازبینی انسانی که مستقل از هر ابزاری کاربرد دارند. و **لایه B، پیاده‌سازی با ابزار**؛ ابزارهای مشخصی مثل OpenCode و oh-my-openagent که این اصول را عملی می‌کنند. اما مهم‌تر از خود ابزارها، یادگیری اصول پایدار است؛ چون ابزارها ممکن است تغییر کنند، ولی اصول می‌مانند.

نکته کلیدی این است: هوش مصنوعی جایگزین شما نمی‌شود، اما شما را قوی‌تر می‌کند. وقتی بدانید چطور از Agent برای شناسایی کد استفاده کنید، چطور تست‌های خودکار بسازید، چطور خروجی Agent را اعتبارسنجی کنید و چطور مدل‌های مختلف orchestration را انتخاب کنید، سرعت و کیفیت کارتان چند برابر می‌شود.

### اهداف یادگیری

**اصول پایدار (لایه A):**
- اصول کدنویسی Agentic و نحوه کاوش در کد را بفهمید
- برای پروژه تست بنویسید و خروجی Agent را اعتبارسنجی کنید
- کد را ریفکتور کنید
- مفهوم Orchestration و جداسازی برنامه‌ریزی از اجرا را بفهمید
- اهمیت مجوزهای ابزار و بازبینی انسانی را بدانید

**پیاده‌سازی با ابزار (لایه B):**
- OpenCode و oh-my-openagent را نصب و راه‌اندازی کنید
- از Ultrawork برای وظایف پیچیده استفاده کنید
- Categories و Skills را بشناسید و درست استفاده کنید
- Team Mode را برای پروژه‌های تیمی درک کنید

### ساختار کارگاه

**بخش ۱: معرفی ابزارها (لایه B)**
- OpenCode چیست؟
- oh-my-openagent چیست؟
- چرا این ابزارها مهم هستند؟

**بخش ۲: نصب و راه‌اندازی (لایه B)**
- نصب OpenCode
- نصب oh-my-openagent
- پیکربندی اولیه

**بخش ۳: شناسایی کد با Agent (لایه A)**
- شناسایی کد موجود
- شناسایی الگوها
- تولید گزارش

**بخش ۴: نوشتن تست (لایه A)**
- نوشتن تست خودکار
- نوشتن تست برای کلاس
- اجرای تست‌ها
- ایجاد تست برای یک پروژه واقعی

**بخش ۵: اعتبارسنجی خروجی Agent (لایه A)**
- بررسی تست تولیدشده
- اجرای تست
- بررسی false positive و false negative
- بررسی تغییرات کد
- بازبینی انسانی کد

**بخش ۶: ریفکتورینگ کد (لایه A)**
- ریفکتورینگ خودکار
- بهینه‌سازی کد

**بخش ۷: سیستم Orchestration (لایه A)**
- مفهوم Orchestration
- کی و چطور استفاده کنیم؟
- Categories و Skills

**بخش ۸: Ultrawork در عمل (لایه B)**
- Ultrawork چیست؟
- مراحل Ultrawork

**بخش ۹: جمع‌بندی و سؤالات**
- خلاصه مفاهیم کلیدی (هر دو لایه)
- سؤال و پاسخ
