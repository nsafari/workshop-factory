## چرا این کارگاه مهم است؟

یک LLM به‌تنهایی عمدتاً تولید محتوا انجام می‌دهد؛ یک Agent-based system می‌تواند از مدل برای تصمیم‌گیری و انتخاب/اجرای ابزارها در یک فرایند چندمرحله‌ای استفاده کند. این تفاوت کوچک، دنیای بزرگی دارد. اگر بتوانید Agent بسازید یا از ابزارهای هوشمند استفاده کنید، دیگر محدود به پاسخ‌های آماده نیستید. خودتان می‌توانید فرآیندها را خودکار کنید، داده‌ها را تحلیل کنید و وظایف پیچیده را قدم‌به‌قدم انجام دهید. این کارگاه شما را با دنیای جدیدی آشنا می‌کند که در آن هوش مصنوعی فقط مشاور نیست، همکار شماست.

اما نکته مهم‌تر این است: یاد می‌گیرید چطور این ابزارها را کنترل کنید. Harnessing یعنی مهار کردن هوش مصنوعی، نه اینکه مهارش کند. وقتی بدانید چطور Guardrails بگذارید، چطور نظارت انسانی حفظ کنید و چطور از ابزارها استفاده کنید، می‌توانید ریسک خطا را کاهش دهید و مشخص کنید Agent در چه شرایطی باید متوقف شده و تصمیم را به انسان واگذار کند. خودتان تصمیم می‌گیرید هوش مصنوعی کجا کار کند و کجا متوقف شود.

## نکات مهم برای شرکت‌کنندگان

### اصطلاحات فنی این کارگاه
در این کارگاه با اصطلاحاتی مثل **Agent**، **Harnessing**، **Guardrails** و **Human-in-the-loop** آشنا می‌شوید. این اصطلاحات به زبان انگلیسی هستند چون بار معنایی دقیقی دارند. مثلاً «Agent» فقط یک ربات نیست، بلکه سیستمی است که با کمک مدل زبانی، در یک فرایند چندمرحله‌ای تصمیم می‌گیرد، ابزار مناسب را انتخاب و اجرا می‌کند و بر اساس نتیجه، گام بعدی را برمی‌دارد.

### نفهمیدن اصطلاحات
اگر اصطلاحی مثل «Guardrails» یا «Harnessing» را نفهمیدید، **نگران نباشید**. مهم‌تر از فهم تک‌تک کلمات، فهم کلی مطلب است. مثلاً اگر نفهمیدید Harnessing یعنی چه، فقط بدانید یعنی «مهار کردن هوش مصنوعی». بقیه مفاهیم را با کمک مثال‌های عملی یاد بگیرید.

### سؤال از مدرس
اصطلاحاتی مثل **Agent**، **Harnessing** و **Guardrails** در این کارگاه **پرتکرار** و **مرکزی** هستند. اگر یکی از آنها را نفهمیدید، حتماً سؤال کنید. فهم این مفاهیم به شما کمک می‌کند هوش مصنوعی را کنترل کنید، نه اینکه هوش مصنوعی شما را کنترل کند.

## ساختار کارگاه

### بخش ۱: معرفی مفهوم Agent (۲۰ دقیقه)

#### ۱.۱ LLM ساده در مقابل Agent (۵ دقیقه)
- LLM ساده: فقط پاسخ می‌دهد
- Agent: تصمیم می‌گیرد و عمل می‌کند
- قیاس: دفترچه راهنما در مقابل دستیار واقعی

#### ۱.۲ Agent چیست؟ (۵ دقیقه)
- تعریف: سیستمی که در یک حلقه تصمیم‌گیری، با توجه به هدف، وضعیت و زمینه (Context)، ابزار مناسب را انتخاب و اجرا می‌کند و بر اساس نتیجه، گام بعدی را برمی‌دارد
- اجزای کلیدی:
  - زمینه (Context): اطلاعات فعلی مکالمه و محیط
  - وضعیت (State): وضعیت فعلی فرایند و مراحل انجام‌شده
  - حافظه (Memory): نگهداری اطلاعات از تعاملات قبلی
  - ابزارها (Tools): قابلیت‌های خارجی که Agent می‌تواند فراخوانی کند
  - برنامه‌ریزی (Planning)
  - اجرا (Execution)

#### ۱.۳ چه زمانی استفاده از Agent ارزشمند است و چه زمانی یک workflow ساده بهتر است؟ (۱۰ دقیقه)
- محدودیت‌های LLM ساده:
  - فقط به سؤالات پاسخ می‌دهد
  - نمی‌تواند عمل کند
  - حافظه کوتاه‌مدت دارد
- مزایای Agent:
  - انجام وظایف پیچیده
  - استفاده از ابزارها
  - حفظ زمینه مکالمه
  - یادگیری از بازخورد
- چه زمانی یک workflow ساده بهتر است؟
  - وظیفه ساده و یک‌مرحله‌ای است
  - پیچیدگی و هزینه Agent توجیه ندارد
  - خطا هزینه کمی دارد و به‌راحتی قابل اصلاح است

### بخش ۲: مشکلات و راه‌حل‌ها با Agent (۲۰ دقیقه)

#### ۲.۱ مشکل ۱: وظایف پیچیده (۵ دقیقه)
- **مشکل**: LLM ساده نمی‌تواند وظایف چندمرحله‌ای را انجام دهد
- **مثال**: "گزارش فروش ماهانه را تهیه کن و به مدیر ایمیل بزن"
- **راه‌حل Agent**: تفکیک وظیفه و اجرای مرحله‌به‌مرحله

#### ۲.۲ مشکل ۲: نیاز به ابزارها (۵ دقیقه)
- **مشکل**: LLM به اینترنت، پایگاه داده یا نرم‌افزار دسترسی ندارد
- **مثال**: "قیمت دلار امروز چند است؟"
- **راه‌حل Agent**: استفاده از ابزارهای خارجی

#### ۲.۳ مشکل ۳: فراموشی در مکالمه‌های طولانی (۵ دقیقه)
- **مشکل**: LLM فراموش می‌کند چه چیزی گفته شده
- **مثال**: مکالمه طولانی با مشتری
- **راه‌حل**: برخی سیستم‌های Agentic از حافظه بلندمدت استفاده می‌کنند تا زمینه مکالمه را حفظ کنند؛ این یک قابلیت انتخابی است، نه ویژگی همه Agentها

#### ۲.۴ مشکل ۴: خطا و بهبود (۵ دقیقه)
- **مشکل**: LLM از اشتباهات خود یاد نمی‌گیرد
- **مثال**: پاسخ نادرست به سؤال تکراری
- **راه‌حل Agent**: یادگیری از بازخورد و بهبود مستمر

#### ۳.۳ Harnessing چیست؟ (۱۰ دقیقه)
- تعریف: کنترل و هدایت Agent
- چرا ضروری است؟
  - جلوگیری از عملکرد نادرست
  - حفظ امنیت
  - اطمینان از کیفیت خروجی

##### روش‌های Harnessing:
1. **محدودیت‌ها (Guardrails)**
   - محدود کردن دسترسی به ابزارها
   - تعیین حد پردازش
   - مثال: "فقط از APIهای تأیید شده استفاده کن"

2. **نظارت انسانی (Human-in-the-loop)**
   - تأیید انسانی قبل از اجرا
   - بررسی خروجی‌ها
   - مثال: "قبل از ارسال ایمیل، به کاربر نشان بده"

3. **بازخورد و اصلاح (Feedback Loop)**
   - یادگیری از اشتباهات
   - بهبود مستمر
   - مثال: "اگر پاسخ نادرست بود، اصلاح کن"

4. **ثبت و گزارش (Logging)**
   - ثبت تصمیمات Agent
   - امکان بازبینی
   - مثال: "هر عملیات را لاگ کن"

##### مثال عملی:
```python
# Harnessing با Guardrails
from langchain.agents import initialize_agent, Tool

def safe_search(query):
    # فقط جستجو در منابع تأیید شده
    allowed_sources = ["wikipedia.org", "stackoverflow.com"]
    return search(query, allowed_sources)
```

### بخش ۴: نمونه استفاده عملی (۲۰ دقیقه)

#### ۴.۱ نمونه ۱: دستیار نوشتن (۵ دقیقه)
```python
# استفاده از LangChain برای نوشتن مقاله
from langchain.llms import OpenAI
from langchain.agents import initialize_agent, Tool

# تعریف ابزارها
def search_web(query):
    # شبیه‌سازی جستجو در وب
    return f"نتیجه جستجو برای: {query}"

def write_article(topic):
    # شبیه‌سازی نوشتن مقاله
    return f"مقاله درباره {topic} نوشته شد"

# تعریف ابزارها برای Agent
tools = [
    Tool(name="Search", func=search_web, description="جستجو در وب"),
    Tool(name="Write", func=write_article, description="نوشتن مقاله")
]

# ایجاد Agent
agent = initialize_agent(tools, OpenAI(), agent="zero-shot-react-description")

# اجرای Agent
result = agent.run("مقاله‌ای درباره هوش مصنوعی در آموزش بنویس")
print(result)
```

#### ۴.۳ نمونه ۳: اتوماسیون وظایف (۵ دقیقه)
```python
# استفاده از CrewAI برای همکاری تیمی
from crewai import Agent, Task, Crew

# تعریف عوامل
researcher = Agent(
    role="پژوهشگر",
    goal="جمع‌آوری اطلاعات درباره موضوع",
    backstory="تو یک پژوهشگر حرفه‌ای هستی"
)

writer = Agent(
    role="نویسنده",
    goal="نوشتن مقاله بر اساس اطلاعات",
    backstory="تو یک نویسنده خلاق هستی"
)

# تعریف وظایف
research_task = Task(
    description="تحقیق کن و اطلاعات جمع‌آوری کن",
    agent=researcher
)

writing_task = Task(
    description="مقاله بنویس",
    agent=writer
)

# ایجاد تیم
crew = Crew(agents=[researcher, writer], tasks=[research_task, writing_task])

# اجرای تیم
result = crew.kickoff()
```
