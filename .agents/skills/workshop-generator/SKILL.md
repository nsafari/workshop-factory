# Workshop Content Generator Skill

## توضیح
این Skill به شما کمک می‌کند محتوای کارگاه آموزشی تولید کنید. کافی است موضوع و مخاطب را مشخص کنید.

## نحوه استفاده
وقتی کاربر می‌خواهد یک کارگاه آموزشی طراحی کند، این مراحل را دنبال کنید:

### مرحله ۱: جمع‌آوری اطلاعات
از کاربر بپرسید:
1. **موضوع کارگاه** چیست؟
2. **مخاطب** کیست؟ (سطح دانش، تعداد، پیش‌نیاز)
3. **مدت زمان** کارگاه چقدر است؟
4. **هدف اصلی** چیست؟ (دانش، مهارت، نگرش)
5. **خروجی مورد انتظار** چیست؟ (اسلاید، جزوه، تمرین)

### مرحله ۲: طراحی ساختار
بر اساس دانش CLIL و اصول ارائه، ساختار زیر را بسازید:

```
ساختار کارگاه
├── مقدمه (۱۰٪ زمان)
│   ├── خوش‌آمدگویی
│   ├── معرفی اهداف
│   └── ایجاد انگیزه
├── محتوای اصلی (۷۰٪ زمان)
│   ├── بخش ۱: [موضوع]
│   ├── بخش ۲: [موضوع]
│   └── بخش ۳: [موضوع]
├── تمرین و کاربرد (۱۵٪ زمان)
│   ├── تمرین فردی
│   ├── کار گروهی
│   └── ارائه نتایج
└── جمع‌بندی (۵٪ زمان)
    ├── خلاصه نکات کلیدی
    ├── ارزیابی
    └── منابع تکمیلی
```

### مرحله ۳: تولید محتوا
برای هر بخش، موارد زیر را تولید کنید:

#### اهداف یادگیری
```
[دانش‌آموز] + [فعل] + [موضوع] + [شرایط] + [معیار]
```

#### مثال‌های کارشده
```
مرحله ۱: معرفی مسئله
مرحله ۲: تحلیل
مرحله ۳: حل
مرحله ۴: بررسی
مرحله ۵: تعمیم
```

#### فعالیت‌ها
```
فعالیت ورودی: [خواندن/تماشا/گوش دادن]
فعالیت پردازش: [بحث/تحلیل/مقایسه]
فعالیت خروجی: [ارائه/نوشتن/تولید]
```

#### سؤالات ارزیابی
```
سطح پایین: [چیست؟ کیست؟]
سطح میانی: [چرا؟ چگونه؟]
سطح بالا: [نظر شما؟ کدام بهتر است؟]
```

### مرحله ۴: تولید خروجی
خروجی را در قالب زیر ارائه دهید:

```markdown
# [عنوان کارگاه]

**مدت**: [زمان]
**مخاطب**: [توضیح]
**پیش‌نیاز**: [پیش‌نیازها]

---

## اهداف یادگیری
1. [هدف ۱]
2. [هدف ۲]
3. [هدف ۳]

---

## ساختار کارگاه

### بخش ۱: [عنوان] ([زمان])
**هدف**: [هدف بخش]
**فعالیت**: [توضیح فعالیت]
**مثال کارشده**: [توضیح مثال]

### بخش ۲: [عنوان] ([زمان])
...

---

## تمرین‌ها
1. [تمرین ۱]
2. [تمرین ۲]

---

## ارزیابی
- [سؤال ۱]
- [سؤال ۲]

---

## منابع
- [منبع ۱]
- [منبع ۲]
```

## نکات مهم

### اصول CLIL را رعایت کنید
1. **Content**: محتوای تخصصی و عمیق
2. **Communication**: زبان مناسب سطح مخاطب
3. **Cognition**: فعالیت‌های شناختی متنوع
4. **Culture**: اتصال به دنیای واقعی

### اصول ارائه را رعایت کنید
1. اهداف SMART بنویسید
2. مثال‌های کارشده گام‌به‌گام باشند
3. فعالیت‌های تعاملی داشته باشید
4. ارزیابی تکوینی و تراکمی داشته باشید

### خروجی قابل استفاده باشد
1. زمان‌بندی دقیق داشته باشد
2. مواد مورد نیاز مشخص باشد
3. تمرین‌های عملی داشته باشد
4. منابع تکمیلی معرفی کند
