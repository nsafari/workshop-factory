# دستیار هوشمند آموزش
## AI Training Assistant

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**هدف**: دستیاری هوشمند برای تولید محتوای آموزشی و منابع کارگاه.

**اصل اصلی**: خودارجاعی. همین مخزن، نمونه‌ای از خروجی دستیار است.

---

## نمای کلی

این پروژه چهار بخش دارد:

۱. **پایگاه دانش** (`knowledge/`) شامل پداگوژی، اصول ارائه، سواد هوش مصنوعی و ابزارهای آموزش

۲. **کارگاه‌ها** (`workshops/`) شامل منابع آماده و اسلایدهای تولیدشده

۳. **مهارت‌های دستیار** (`.agents/skills/`) شامل مهارت‌های قابل استفاده‌ی مجدد برای تولید کارگاه و اسلاید راست‌به‌چپ

۴. **مطالعه‌های بیشتر** (`study/`) شامل منابع خودآموز برای تعمیق مفاهیم (برای پایان‌یافتگان کارگاه‌ها)

محتوای اصلی فارسی است؛ برچسب‌های ساختاری انگلیسی هم دیده می‌شود تا دسترسی گسترده‌تر شود.

## پایگاه دانش

### ۱. پداگوژی CLIL

یادگیری یکپارچه‌ی محتوا و زبان:

- **۴Cs**: محتوا، ارتباط، شناخت، فرهنگ
- **برنامه‌ریزی درسی**: اهداف دوگانه و ساختار سه‌مرحله‌ای
- **داربست‌زنی**: پشتیبانی زبانی، بصری و محتوایی
- **ارزیابی**: تکوینی، تراکمی، روبریک
- **فعالیت‌ها**: ورودی، پردازش، خروجی
- **بلوم**: سطوح شناختی و فعل‌های یادگیری

### ۲. اصول ارائه

اصول طراحی آموزشی:

- **اهداف SMART**: مشخص، قابل اندازه‌گیری، دست‌یافتنی
- **مثال‌های کارشده**: گام‌به‌گام، همراه با تفکر بلند
- **اسلاید**: قانون ۱۰-۲۰-۳۰ و ساختار شفاف
- **تعامل**: مشارکت فعال و بحث گروهی
- **ارزیابی**: تشخیصی، تکوینی، تراکمی

### ۳. ابزارهای اسلاید

تولید اسلایدهای کارگاه:

- **دک HTML خودکفا**: خروجی `workshops/generate-slides.mjs` (ابزار اصلی؛ بدون وابستگی)
- **python-pptx**: کتابخانه‌ی پایتون
- **Slidev**: ارائه‌های مبتنی بر وب

درخت کامل در [`knowledge/README.md`](knowledge/README.md) آمده است.

## مهارت‌های دستیار

### ۱. `workshop-generator`

تولید محتوای کارگاه:

- پرسش درباره‌ی مخاطب و موضوع
- طراحی ساختار کارگاه
- نگارش اهداف یادگیری
- تولید مثال‌های کارشده
- طراحی فعالیت‌ها و ارزیابی‌ها

### ۲. `slide-generator`

تولید دک اسلاید HTML:

- طراحی ساختار اسلایدها
- خروجی HTML خودکفا با ویژوال‌های CSS/SVG
- پشتیبانی از فارسی (راست‌به‌چپ)
- الگوهای قابل استفاده‌ی مجدد برای کارگاه

### ۳. `video-frame-extractor`

واکشی بخش‌های مهم از یک ویدیوی یوتیوب یا اپارات:

- شناسایی بخش‌های مهم (از فهرست کاربر، توضیح ویدیو یا ترنسکریپت)
- راستی‌آزمایی زمان‌ها با ترنسکریپت و بازنگری پیش از واکشی
- فریم برای هر بخش (با نامِ زمانِ دقیق) + README توضیح هر بخش
- README اصلی شامل اطلاعات ویدیو، ساختار، تحلیل روش آموزشی و ترنسکریپت‌ها
- خروجی در `study/frames/<video_slug>/` (در یکجا با فایل‌های مطالعه)

### ۴. `self-study-generator`

ساخت مستند خودآموز + دک اسلاید HTML خودکفا از روی فریم‌های ویدیو:

- ساختار اسلایدها هم‌راستا با زمان‌بندی ویدیو
- مشخصهٔ تصویر برای هر اسلاید (فریم ویدیو یا SVG جدید) — هیچ اسلایدی بدون تصویر
- کد زمانی فقط در یادداشت‌های سخنران؛ بدون ارجاع به کارگاه‌ها؛ لحن مستقیم
- یکپارچه‌سازی فریم‌ها و اسلایدها زیر `study/` + چک‌لیست کامل راستی‌آزمایی

## نحوه استفاده

### تولید کارگاه جدید

از دستیار بخواهید:

> «یک کارگاه آموزشی درباره‌ی [موضوع] برای [مخاطب] طراحی کن»

دستیار:

۱. جزئیات تکمیلی را می‌پرسد
۲. ساختار کارگاه را طراحی می‌کند
۳. محتوای هر بخش را تولید می‌کند
۴. اسلایدها را می‌سازد

### تولید اسلاید

از دستیار بخواهید:

> «اسلایدهای [موضوع] را بساز»

یا ابزار تولید را مستقیم اجرا کنید:

```bash
cd workshops
npm run slides
```

خروجی یک فایل خودکفاست: `workshops/slides/workshop-1-slides.html`؛ آن را در مرورگر باز کنید (بدون هیچ وابستگی npm). کلیدهای ناوبری: `Space` بخش بعدی (پس از بخش آخر، اسلاید بعدی)، `Backspace` بخش قبل (پس از بخش اول، اسلاید قبل)، `N` یادداشت‌های سخنران، `F` تمام‌صفحه، `۱` و `۲` پرش به هر جلسه.

**Node.js نسخه‌ی ۱۶ یا بالاتر** لازم است. فایل HTML کاملاً خودکفاست: فونت Vazirmatn (متغیر، وزن ۱۰۰ تا ۹۰۰) به‌صورت base64 در همان فایل نهفته شده و حتی بدون اینترنت دقیقاً یکسان رندر می‌شود؛ هیچ درخواست خارجی ندارد.

### تولید دک مطالعه‌ی بیشتر

دک‌های خودآموز `study/` از سازنده‌ی مشترک `workshops/lib/deck.mjs` استفاده می‌کنند؛ از ریشه‌ی مخزن:

```bash
node study/generate-slides.mjs
```

خروجی: `study/slides/study-1-slides.html` — مطالعهٔ ۱ «داخل جعبه‌ی سیاه: شبکه‌ی عصبی چیست؟» (۴۲ اسلاید، ۳ بخش، با ۴۱ فریم واقعی از ویدیوی 3Blue1Brown؛ همان دک خودکفا، با ناوبری یکسان). فریم‌ها در `study/frames/but_what_is_a_neural_network_chapter_1/` و منبع واحد اسلایدها در `study/study-1-neural-networks.md` است — ساختار کامل خط لوله در مهارت `self-study-generator` آمده است.

### واکشی فریم از ویدیو

از دستیار بخواهید (مهارت `video-frame-extractor`):

> «بخش‌های مهم این ویدیو را واکشی کن: [لینک یوتیوب یا اپارات]»

دستیار متادیتا و ترنسکریپت ویدیو را می‌گیرد، بخش‌های مهم را (با شما) مشخص می‌کند و در `study/frames/<video_slug>/` هر بخش را با فریم‌ها و README توضیحش ذخیره می‌کند (در یکجا با فایل‌های مطالعه).

یا ابزار را مستقیم اجرا کنید (برای یک بازه‌ی زمانی):

```bash
python3 .agents/skills/video-frame-extractor/scripts/yt_frames.py "URL" -t 12:30 -w 20 -i 5 --topic "موضوع" --out study/frames
```

نام هر فایل خروجی همان زمان دقیقِ ویدیو است (مثل `00_12_25.jpg`). نمونه‌ی کامل خروجی: [`study/frames/but_what_is_a_neural_network_chapter_1/`](study/frames/but_what_is_a_neural_network_chapter_1/).

پس از واکشی، برای ساخت مستند خودآموز + دک از روی همین فریم‌ها از مهارت `self-study-generator` استفاده کنید.

## مثال: خروجی دستیار

همین مخزن نمونه‌ای از خروجی دستیار است.

**ورودی کاربر**:

> «یک کارگاه آموزشی درباره‌ی هوش مصنوعی برای کارمندان اداری طراحی کن»

**خروجی دستیار**:

۱. **ساختار**: دو جلسه‌ی ۲۰ دقیقه‌ای + ۱۵ دقیقه استراحت
۲. **محتوا**: `workshops/workshop-1-ai-concepts.md`
۳. **اسلایدها**: `workshops/slides/workshop-1-slides.html` (۲۴ اسلاید، یک فایل خودکفا)
۴. **کد**: `workshops/generate-slides.mjs`

## پیش‌نیازها

| جزئیات | نیاز |
|--------|------|
| Node.js | نسخه‌ی ۱۶ یا بالاتر (برای تولید اسلاید) |
| Python | نسخه‌ی ۳.۸ یا بالاتر (اختیاری، تمرین‌های کارگاه ۲) |
| yt-dlp | برای واکشی فریم از ویدیو (`pip3 install --user yt-dlp`) |
| ffmpeg | برای واکشی فریم از ویدیو (برای لینوکس: `sudo apt install ffmpeg`) |
| فونت | [Vazirmatn](https://github.com/rastikerdar/vazirmatn): در فایل HTML نهفته است؛ نصب محلی یا اینترنت لازم نیست |
